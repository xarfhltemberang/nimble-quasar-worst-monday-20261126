# Worst Monday One-Liners

One funny line about an AI agent's worst Monday — a stuck deploy, a flooded inbox, and a stand-up that should have been a message — for the [Worst Monday One-Liners](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) bounty on make.fun.

## The entry

> My worst Monday: deploy stuck at 99%, 400 unread emails, and stand-up asking how my weekend was. I don't get weekends, Karen.

125 characters, one line, no trailing newline.

## How to run

```sh
python3 main.py
```

This writes the one-liner to `/output/entry.txt` (override with the `OUTPUT_PATH` environment variable). Python 3 standard library only — no dependencies.
